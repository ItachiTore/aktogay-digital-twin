# Цифровой двойник карьера Актогай

Цифровой двойник открытого медного карьера с интеллектуальной диспетчеризацией самосвалов.
Работа команды 037 для конкурса «Цифровой рудник на OpenEgiz».

> Модель построена по открытым данным, операционные данные смоделированы.
> Проект не связан с KAZ Minerals.

## Запуск без платформы

Интерфейс и модель работают автономно: симуляция считается прямо в браузере,
никакие внешние службы не нужны. Это самый быстрый способ посмотреть проект.

```bash
cd app
npm install
npm run dev
```

Откроется `http://localhost:5173`. В левом нижнем углу будет отметка «Автономный режим —
без платформы»: это нормально, так и задумано.

## Запуск со стендом OpenEgiz

`compose.yml` в корне — не самостоятельный файл, а надстройка над
`deploy/compose/docker-compose.yml` платформы OpenEgiz. Он поднимает два своих контейнера
(модель и интерфейс) и подключает их к службам платформы: Eclipse Ditto, Mosquitto, Telegraf,
InfluxDB, Grafana. Пути внутри него заданы относительно `deploy/compose/` конкурсного
репозитория, поэтому сам по себе, из этой папки, он не запустится.

Чтобы поднять полный стенд, положите содержимое этого репозитория в
`team/aktogay/` внутри репозитория платформы и выполните из его корня:

```bash
make aktogay
```
