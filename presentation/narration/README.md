# Озвучка и сборка роликов

Здесь лежит всё, чем сделана звуковая дорожка к демо-ролику и ролик-обзор интерфейса.

## Что получилось

| Файл | Что это |
|---|---|
| `../aktogay-demo-ru.mp4` | Демо карьера с озвучкой и музыкой, 2 мин 55 с, исходное качество |
| `../aktogay-demo-ru-web.mp4` | Он же, сжатый для веб-страницы |
| `../aktogay-ui-tour-ru.mp4` | Обзор интерфейса: 12 разделов сайта, 2 мин 3 с |

Голос — ElevenLabs, модель `eleven_multilingual_v2`, голос George.
Музыкальная подложка синтезирована ffmpeg из расстроенных синусоид (`bed.js`),
поэтому прав третьих лиц в роликах нет и указывать автора музыки не требуется.

Замеры готовых дорожек: −14 LUFS, разброс 2–3 LU, пауз полной тишины нет.

## Тексты

- `lines.json` — реплики к демо-ролику с таймкодами (`at` — секунда начала)
- `ui-lines.json` — реплики к обзору интерфейса, по одной на раздел
- `ozvuchka.md` — тот же текст в читаемом виде, если захочется начитать живым голосом

Название карьера записано как «Актоугай»: так синтез произносит среднюю «о»
как «о», а не редуцирует её в «а».

## Скрипты

Ключ ElevenLabs берётся из `%USERPROFILE%\.elevenlabs_key` или переменной
`ELEVENLABS_API_KEY` и нигде не печатается. Путь к ffmpeg — в переменной `FFMPEG`.

| Скрипт | Что делает |
|---|---|
| `eleven.js` | Озвучивает `lines.json` → `cueNN.wav` |
| `uivoice.js` | Озвучивает `ui-lines.json` → `uiNN.wav`, с докачкой при обрыве сети |
| `gen.js` | То же через Piper (локальный синтез, запасной вариант) |
| `bed.js` | Синтезирует музыкальную подложку нужной длины |
| `mux.js` | Кладёт реплики на видео по таймкодам |
| `mux2.js` | То же плюс подложка с приглушением под голосом |
| `shoot.js` | Снимает разделы интерфейса через Chrome DevTools Protocol |
| `shoot2.js` | Доснимает пульт диспетчера и терминал водителя после демо-входа |
| `buildui.js` | Собирает ролик-обзор: кадры, переходы, озвучка, подложка, мастеринг |
| `tts.ps1` | Запасной синтез средствами Windows (русского голоса в системе обычно нет) |

### Как пересобрать обзор интерфейса

```bash
cd app && npm run dev          # поднять приложение на :5173
# запустить Chrome с отладочным портом, затем:
node shoot.js 9222 "http://localhost:5173/?quality=high&lang=ru" ./ui
node shoot2.js 9222 "http://localhost:5173/?quality=high&lang=ru" ./ui
node uivoice.js
NOZOOM=1 CRF=20 node buildui.js <путь-к-ffmpeg> out.mp4
```

Длительность кадра не задаётся вручную: она равна длине своей реплики плюс
полторы секунды, поэтому фразы не обрываются на смене кадра.
