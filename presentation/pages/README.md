# Страницы о проекте

Три самостоятельные HTML-страницы: открываются двойным щелчком, сервер не нужен.
Шрифты подгружаются из Google Fonts, без интернета подставятся системные.

| Файл | Что показывает |
|---|---|
| `index.html` | Обзор проекта: что сделано, из чего собрано, ссылки на репозиторий и заявку |
| `steps.html` | Экскурсия по проекту с демо-роликом и разбором по шагам |
| `map.html` | Где двойник решает какую задачу: 3D-макет комбината и десять проблемных точек |

`map.html` рисует трёхмерную сцену через `scene3d.js` (three.js с CDN). Без WebGL
страница сама переключается на плоскую схему — это предусмотрено, не поломка.

`steps.html` проигрывает `../aktogay-demo-ru-web.mp4` и показывает снимки из `shots/`.

В `ui/` — двенадцать снимков разделов интерфейса в разрешении 1600×900, снятые
с работающего приложения. Из них собран ролик-обзор `../aktogay-ui-tour-ru.mp4`.
